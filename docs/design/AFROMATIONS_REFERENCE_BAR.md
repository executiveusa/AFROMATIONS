# AFROMATIONS Reference Bar

## Purpose
Use real sites as fetchable bars for research and browser comparison. Extract mechanics and visual principles. Do not clone visual expression.

## Primary reference set

### Hellboy: Web of Wyrd launch site
Role in the bar: **mood, restraint, world-building, negative space, IP-authentic composition**.

Useful principle: make the site feel like an extension of the creative universe rather than a generic software landing page.

AFROMATIONS application: cinematic entry, bold art direction, limited copy, controlled pacing, clear action beneath the world-building.

### Studio TRIGGER
Role in the bar: **studio identity + original work + goods + community channels**.

Useful principle: the studio leads with WORK, then news/recruit/goods. Original IP strengthens the studio brand.

AFROMATIONS application: make work and original characters visible immediately; merchandise and community are natural extensions, not disconnected widgets.

### MAPPA
Role in the bar: **current work as primary proof, sparse navigation, strong project imagery**.

Useful principle: portfolio proof carries the brand more than explanatory copy.

AFROMATIONS application: show real projects, artist footage, DUAL, Hana, murals, manga, and finished outputs early.

### Science SARU
Role in the bar: **clear studio philosophy + works + people/interviews**.

Useful principle: a studio can combine business, art, culture, and human voices without becoming a corporate brochure.

AFROMATIONS application: editorial artist interviews and Seattle community work become proof of culture and company purpose.

### ufotable
Role in the bar: **works + commerce + fan experience ecosystem**.

Useful principle: the studio brand can extend from production into shops, physical experiences, goods, and fan touchpoints.

AFROMATIONS application: Printify merchandise, manga, community projects, live interviews, and studio products can sit under one parent brand.

### Fortiche
Role in the bar: **distinctive human-authored visual signature and original IP credibility**.

Useful principle: technology should support a recognizable art philosophy rather than become the identity.

AFROMATIONS application: position AI as infrastructure around human artists, not the visual headline.

## Gauntlet use
Browser agent must capture matched desktop and mobile screenshots of each live reference and AFROMATIONS. Compare:
- first 2 seconds
- hero composition
- work/proof sequencing
- navigation density
- typography
- image-to-copy ratio
- CTA clarity
- cultural authorship
- mobile transformation
- merchandise/community integration
- amount of generic AI language

## AFROMATIONS design thesis to test
AFROMATIONS should feel like a Seattle-rooted art/anime studio and community platform that happens to have strong AI infrastructure behind it. The public experience should be more visual than explanatory, but never unclear.
