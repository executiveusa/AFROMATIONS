# AFROMATIONS Control Plane v2

## Outcome
Tyshawn can operate AFROMATIONS and its StarNet world by speaking naturally to Instinct. The system hides internal complexity, prepares work, asks only for consequential approvals, and returns verified results.

## Control hierarchy

Tyshawn
→ Instinct (private WhatsApp control surface)
→ Hana (AFROMATIONS first mate / studio operator)
→ bounded specialists and tools
→ canonical state / receipts
→ Tyshawn

## Runtime decision
Hana is the public identity and operating role.

Current implementation evidence shows:
- Hermes Agent is configured to run the Hana/Hanna persona and persistent memory/tool layer.
- Pi is named in canon as the build harness / agent manager for coding and software-production work.

Therefore:
- Hermes = persistent Hana runtime brain.
- Pi = software/build harness delegated when needed.
- Instinct = private owner-facing command surface.
- Hana = studio first mate that receives intent and supervises execution.

Do not create two competing top-level Hanas.

## DUAL
DUAL is currently best treated as flagship original IP/product and proof-of-work. A DUAL-specific agent may exist later with a bounded charter, but it should not duplicate Hana's authority by default.

## Public company model
AFROMATIONS Studio is a Seattle-rooted social-purpose art and creative-technology company.

Primary public purpose:
**connect real artists to real paid work while building original creative IP and useful creator infrastructure.**

Public pillars:
1. Work / original IP — DUAL, Hana, manga, animation, studio projects.
2. Artist opportunities — mural, cleanup, illustration, production, collaborations.
3. Community — Seattle / Northwest projects and social-purpose initiatives.
4. Products — Agent Hana, AfroScribble, manga systems, creator tools.
5. Editorial — artist interviews, podcast/video, studio stories, community coverage.
6. Commerce — merchandise, services, licensed drops, studio products.

## Firstmate behavior
Hana uses Firstmate principles:
- one liaison
- mission decomposition
- clean specialist handoffs
- durable state
- isolated coding work where practical
- approval gates
- restart-safe progress
- plain-language receipts

## Human approval gates
Required for publishing, spending, merchandise orders, pricing changes, legal/licensing commitments, destructive actions, new permissions, money movement, production releases when policy requires, voice/likeness cloning, and model training on artist assets.

## Public website rule
The public website does not expose this internal topology. It shows:
- who AFROMATIONS is
- selected work
- real people and collaborations
- opportunities
- products
- community impact
- clear next actions

The control plane is powerful. The public experience is simple.
