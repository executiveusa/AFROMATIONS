# ADHD Elegant Simplicity

## Prime law
What can be removed while making the human more successful?

Optimize for minimum cognitive effort + minimum physical effort + maximum confidence + maximum usefulness.

## Defaults
- One dominant purpose per screen.
- Keep system state visible.
- Use progressive disclosure.
- Do not make the human remember what the system can remember.
- Do not make the human configure what the system can safely infer.
- Put the next important action where it is obvious.
- Chunk complexity.

## Decision hierarchy
User outcome → clarity → trust → ease → speed → accessibility → consistency → delight → polish → novelty.

## Human control
For publishing, spending, deletion, purchases, infrastructure changes, legal commitments, permission changes, and other consequential actions:
AI prepares → human verifies → system executes.

## Design law
Every element must help the user understand, decide, act, verify, recover, or succeed. If it does none of those, challenge its existence.

## AFROMATIONS operator rule
Tyshawn should be able to state intent in natural language. Instinct and Hana hold context, prepare work, route specialists, and surface only the approvals that materially matter.
