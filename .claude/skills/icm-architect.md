# ICM Architect

Use ICM to keep long-lived agent work coherent.

## Core model
Separate:
- FACTS: verified current reality
- ASSUMPTIONS: plausible but unverified
- DECISIONS: owner-approved choices
- QUESTIONS: unresolved items with an owner
- CONSTRAINTS: protected boundaries
- EVIDENCE: links, files, screenshots, tests, receipts

## Required behavior
- Preserve a single canonical project context.
- Do not force the user to restate known context.
- Update decisions when new evidence invalidates an old assumption.
- Make approval points explicit only where business, money, legal, publishing, destructive, or ownership consequences exist.
- Keep implementation details out of the user-facing layer unless needed.
