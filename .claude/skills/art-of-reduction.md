# Art of Reduction

Use subtraction as an active design and architecture step.

For every surface ask:
- Can this be removed?
- Can this be combined?
- Can the system infer it?
- Can the system remember it?
- Can the system prepare it?
- Can it appear only when needed?
- Can this sentence be shorter without losing meaning?
- Can the workflow require fewer decisions?
- Can advanced capability live behind a detail surface?

Stop removing when another subtraction would harm comprehension, trust, accessibility, recovery, commercial value, or human authority.

For AFROMATIONS, keep the public site visually rich but cognitively simple: studio → work → proof → opportunity → action.
