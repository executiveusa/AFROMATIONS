# New Look

A visual reset is not permission to reinvent the business.

## Inputs required
- project lock
- verified audience and offer
- evidence ledger
- reference ledger
- protected assets
- mobile contract

## Output
Create materially different visual territories with:
- governing idea
- grid
- typography behavior
- palette logic
- image treatment
- motion purpose
- navigation behavior
- signature moment
- mobile transformation
- accessibility/performance risks

The selected system must remain recognizable without the logo and must be rooted in AFROMATIONS' real art, Seattle context, original IP, artist collaborations, and community work.

Do not copy the reference sites. Extract principles and mechanics.
